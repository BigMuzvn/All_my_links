# Assets — où mettre tes fichiers

## 📷 `photos/`
| Fichier attendu | Usage | Conseils |
|---|---|---|
| `godson.jpg` (ou `.png` / `.webp`) | Ta photo de profil, affichée en grand en haut de page avec le fondu | Portrait (vertical), idéalement ≥ 1080px de large, bien éclairée en haut (le bas sera fondu dans le noir) |
| `ctn-mafia.png` (ou `.jpg` / `.svg`) | Logo du label CTN Mafia, affiché sur sa vue | Carré de préférence, ≥ 500×500px, fond transparent si possible |

## 🔗 `icons/`
Les vraies icônes des plateformes, **format SVG de préférence** (sinon PNG ≥ 96×96px, fond transparent).

Noms de fichiers attendus (en minuscules) :
- `instagram.svg`
- `email.svg`
- `snapchat.svg`
- `whatsapp.svg`
- `x.svg`
- `youtube.svg`
- `tiktok.svg`
- `facebook.svg`

> 💡 Bonnes sources d'icônes officielles : [simpleicons.org](https://simpleicons.org) (SVG monochromes de toutes les marques, télécharge et renomme), ou les press kits officiels des plateformes.

Si un nom de fichier diffère, pas grave — dis-le-moi et j'adapterai la config (`links.json`).
